# Dwelling on the Hill · Yeraltı konseptleri

54 konsept, 7 mimari plan/kesit ve etkileşimli mekanik anlatımı. `index.html` ana sayfadır. `real.html` tarihsel yapı referanslarını sunar.

Konseptler yapay zekâ destekli tasarım çalışmalarıdır; gerçek oyun görüntüsü, onaylanmış bölüm tasarımı veya performans kanıtı değildir. Ölçüler tasarım önerisidir. Harici fotoğraflar kaynak sunucularından yüklenir; internet bağlantısı gerekir ve telifleri ilgili sahiplerindedir. Kaynak model dosyaları ve ürün önizleme kopyaları bu depoda yoktur.
